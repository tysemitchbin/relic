Relic glyph — anchoring mockup

Every track in a relic, each scaled independently to the same size and stacked on a common anchor. A anchors each track on its bounding-box centre, so the lines cross each other. B anchors each track on its start point, so they radiate. Flights ignore their geometry entirely and draw as a fixed arc rotated to the flight's true bearing.
