Relic glyph — anchoring + stylisation

Every track in a relic, each scaled independently to the same size and stacked on a common anchor. A centres each track's bounding box, so lines cross. B pins each track's start point, so they radiate. Flights discard their geometry and draw as a fixed arc rotated to the true bearing. The style control decides how much the raw trace is rewritten into a constrained stroke vocabulary.

Automatic — recipe chosen from the tracks

No knobs. Each relic is measured, a recipe is picked, and the glyph is composed to that recipe. Every relic below is rendered by the same function.

Colour — matched to the user's map palette

Each stroke takes its track's colour, resolved exactly as the map does: m.customColor || getColor(m.type), after loadColors() has applied the user's own overrides. Multiply darkens where strokes cross, which reads as depth in one hue and can go muddy across several.
