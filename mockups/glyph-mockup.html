Relic glyph — anchoring + stylisation

Every track in a relic, each scaled independently to the same size and stacked on a common anchor. A centres each track's bounding box, so lines cross. B pins each track's start point, so they radiate. Flights discard their geometry and draw as a fixed arc rotated to the true bearing. The style control decides how much the raw trace is rewritten into a constrained stroke vocabulary.
